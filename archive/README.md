# Archived code

This directory contains superseded experiments and adapters that are retained
for auditability. They are not part of the current judge-facing dashboard.

- `analysis.py` — former persistent school-campus residual analysis.
- `gemini_adapter.py` — former residual-specific Gemini adapter.
- `profile.py` — former profile-context guardrail work.

See [`docs/ARCHIVE.md`](../docs/ARCHIVE.md) for the complete archive map and
the current dashboard path.
